# 08_understanding/ — what to read

Two documents.

## `00_HANDBOOK.md` — start here

The single reference for the project: the problem, the research gap, the method,
every experiment and result, an honest assessment, prepared answers to hard
questions, what remains to be done, and where every file lives.

Written to be read straight through before a presentation. Part 0 is a one-page
summary if that is all you have time for; a self-quiz at the end checks whether
it stuck.

## `03_domain_adaptation_deep_dive.md` — the six survey papers

The detailed study of the domain-adaptation surveys assigned by the supervisor:
what each paper contributes, the four types of shift, and the vocabulary a panel
may test. The Handbook condenses the parts this project depends on; this is the
full treatment.
