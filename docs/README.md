## What's in each folder

**`00_PLAN.md`** — the canonical Sem-3/Sem-4 plan. The single source of truth for direction.

**`01_literature/`** — paper reading list, per-paper summaries, the domain-adaptation notes,
and the IEEE literature survey (`.tex`). Open when reading or citing prior work.

**`02_proposal/`** — research proposal, topic pitch (v3), problem-statement talking points,
the video-AD future-scope note. *Frozen Sem-2 deliverables* — historical, rarely edited now.

**`03_progress_reports/`** — dated progress reports (`.tex`) for regular professor updates.
`research_progress.tex` is the maintainable one — add a new row each time you make progress.

**`04_thesis/`** — the growing final thesis, in parts (`part1`–`part4`). This is where new
results get written up.

**`05_viva/`** — **`viva_questions_final.md` is the START-HERE master.** The deeper/older
question banks (`viva_questions_55.tex`, `viva_preparation_bible.tex`) are kept in `_archive/`
if you want extra practice questions.

**`06_presentations/`** — slide decks (`.pptx`/`.pdf`), the presentation scripts, and the
compiled report PDF. Latest deck = the one to reuse.

**`07_reference_papers/`** — external reference papers as PDFs (e.g. *Quo Vadis, Anomaly
Detection?*).

**`_archive/`** — superseded duplicates kept for safety. Nothing here is current; ignore it
unless you're looking for something that used to exist.
